# [ft_printf]

*This project has been created as part of the 42 curriculum by nraatika.*

---
### Goal
Recreate the `printf`function in **C**. Handles the flags `cspdiuxX` specifying input type, and precision and padding flags `-.0+ #`, as well as minimum width specifiers. And of course, a variadic argument list.
### Compilation
To compile the project, run the following command in the root directory:

```bash
make
```
or
```bash
make bonus
```
will make a library file containing the `ft_printf` function, with the baseline version containing all the specific input types, and the bonus version also including handling the extra flags for width, precision and padding.
