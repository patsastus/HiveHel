# [get_next_line]

*This project has been created as part of the 42 curriculum by nraatika.*

---
### Goal
Create a function in **C** to read a line from a file descriptor (or a set of file descriptors). Accepts a compile-time constant to set the buffer size the reader uses internally.
### Compilation
To compile the project, run the following command in the root directory:

```bash
make
./
```
