# [libft]

*This project has been created as part of the 42 curriculum by nraatika*

---
### Goal
Recreate some **C** standard library functions to get familiar with pointers and memory management in **C**.
### Compilation
To compile the project, run the following command in the root directory:

```bash
make
```
This makes the `libft.a` library, used throughout our subsequent projects.
